# مندوب الصيدليات

تطبيق ويب مجاني للجوال (PWA) لمندوب يبيع للصيدليات:
- خريطة (OpenStreetMap) بيها كل الصيدليات، وزر GPS يجيب موقعك.
- تضغط على الدبوس ← "افتح بويز" يوديك على Waze.
- الصيدليات مرتبة حسب المنطقة، ولكل صيدلية ملاحظات ورقم هاتف ورابط موقع.
- زيارات/مهام بتاريخ، وصفحة "اليوم" تطلعلك زيارات اليوم والمتأخرة والقادمة.
- البيانات محفوظة على الجوال نفسه، وبيه تصدير/استيراد نسخة احتياطية.

## الرفع على GitHub Pages
1. ارفع كل الملفات بمستودع على GitHub.
2. Settings ← Pages ← Source: Deploy from a branch ← Branch: main و / (root) ← Save.
3. بعد دقيقة يصير الرابط: `https://USERNAME.github.io/REPO/`

## إضافته للشاشة الرئيسية
- آيفون (Safari): زر المشاركة ← "إضافة إلى الشاشة الرئيسية".
- أندرويد (Chrome): القائمة ⋮ ← "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
