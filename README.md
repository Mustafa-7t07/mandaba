# مندوب الصيدليات

تطبيق ويب مجاني للجوال (PWA) لمندوب يبيع للصيدليات.

- **الرئيسية:** المشاكل العالقة، مهام اليوم والمتأخرة، الزيارات المعتادة لهذا اليوم، والقادمة.
- **الخريطة:** كل الصيدليات بلون منطقتها، وزر GPS، وإضافة صيدلية بمكانك أو بالضغط المطوّل.
- **تخطيط الجولة 🧭:** تختار زيارات اليوم أو منطقة معينة، والبداية (موقعك أو صيدلية) والنهاية، فيرتبهن من الأقرب للأبعد حسب الطرق (OSRM) ويرسم الطريق، مع زر ويز لكل محطة ورابط كوكل ماب للجولة كلها.
- **الزبائن:** بحث بالاسم أو الرقم، وفلتر حسب المنطقة. لكل صيدلية: المسؤول، هاتفين، العنوان، الموقع، أيام الزيارة المعتادة، ملاحظات، وسجل الزيارات والمهام والمشاكل.
- **المشاكل:** مفتوحة لحد ما تنحل.
- **الإعدادات:** المناطق وأيام زيارة كل منطقة، ونسخة احتياطية (تصدير/استيراد).

البيانات محفوظة على الجوال نفسه (localStorage).
